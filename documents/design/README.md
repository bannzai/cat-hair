# documents/design

bannzai に見てもらって決める物の置き場。見た目と体験の方向を決めるためのモック・受領したデザインと、新しい保存データの形の案を、日付か用途ごとのディレクトリに置く。決まった内容は [../DIRECTION.md](../DIRECTION.md) の「デザインの方向」「決めたこと」に書き、ここには見てもらった時点の物を残す。

| ディレクトリ | 中身 |
| --- | --- |
| `save-data-2026-11-25/` | 保存データの形の案 (型定義と、利用者の操作ごとに読み書きするデータの表)。`index.html` をブラウザで開く |
| `look-prototype-2026-11-26/` | 見た目の試作 (屋敷の 1 部屋と画面の表示) を CI で撮った 3 つの状態の PNG。各 PNG の状態・見本の値・参考の動画から取り入れた点は同じ場所の `README.md` |
