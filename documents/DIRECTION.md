# 方向性: cat-hair (題名は未定。リポジトリ名を仮の名前に使う)

## 仮説

Steam で 300〜900 円の短編インクリメンタルを買って数時間で遊び切る PC のプレイヤーは、同種の作品に「短すぎる・唐突に終わる」「終盤が待つだけになる」という不満を持っている。猫の毛を手で 1 本ずつ抜くみみっちさを写実寄りの一人称 3D で気持ちよく・アホらしく見せ、取りこぼし・猫がまた落とす毛・探し物を傷めない道具の持ち替えで自動化の後もやることを残せば、手で取る段階の手触りと、全自動にした時の「最高」の両方が遊ぶ理由になる。

## 判定基準

評価レポートの全文は作るかの判断の issue にある (評価時点のスナップショット。以後の更新は本文書だけに書く)。ウィッシュリスト数を castle の skill かコマンドで読む経路が無いため、その行の計測元はストアページを出す時に決め直す。

| 指標 | 計測元 (skill / コマンド) | 継続のしきい値 | 打ち切り条件 | 転換の条件 |
| --- | --- | --- | --- | --- |
| 毛の描画 (屋敷の 1 部屋に置ける毛の本数) | CI の描画付きの job が残す録画と、毛の本数ごとの 1 フレームの描画時間の集計 (ロードマップの最初の issue で作る `make hairbench`。artifact を `gh run download` で取得)。実機の fps は bannzai が `make run` で見る | CI で 10 万本を描画でき、録画が真っ黒でない | 2 回作り直しても CI で 1 万本を描画できない | 1 本ずつのメッシュで足りない → 遠くの毛をテクスチャに置き換える・見せる本数と数える本数を分ける |
| 最初の屋敷の所要時間 (bot が手で取る段階から全自動まで進める時間) | `make simulate` (ロードマップで作る。CI の artifact の集計 JSON を `gh run download` で取得) | 手で取る段階 10〜15 分、次の建物へ進めるまで 60〜120 分 | 2 回調整しても 30 分未満か 240 分超 | 短い → 毛の総本数か道具の値段を上げる。長い → 中盤の道具の取れる本数を上げる |
| 触れる版 (屋敷を手で取る段階から最初の自動化まで遊べる版) での bannzai の感想 | 触れる版の報告の issue への bannzai のコメント (`gh issue view <番号> -R bannzai/cat-hair --json comments`) | 「手で取るのが気持ちいい・アホらしい」 | 2 回続けて「作業なだけで面白くない」 | 「手触りが弱い」→ 抜ける時の伸び・音・カウントの演出を変える。「自動化が気持ちよくない」→ 自動化の前後の差の見せ方を変える |
| ストアページ公開後 28 日のウィッシュリスト数 | Steamworks の画面 (コマンドで読む経路が無い。ストアページを出す時に経路と一緒に決め直す) | 2,000 件以上 | 200 件未満 | 訪問はあるがウィッシュリストに入らない → ストアの最初の画像と動画を、猫と取りこぼしが伝わるものに変える |
| 発売後 28 日のレビュー数 (全言語・全購入種別) | `curl -sS 'https://api.steampowered.com/IUserReviewsService/GetAppReviews/v1/?appid=<appid>&review_type=0&purchase_type=1&num_per_page=0'` の `response.query_summary.total_reviews` | 50 件以上 | 2 回連続 (56 日) で 10 件未満 | レビュー数はあるが好評率 70% 未満 → 否定レビューの上位の不満を直す |

## 必要な機能

作るかの判断の issue で bannzai に過不足を見てもらう一覧 (下書き)。遊びの中身の全文は [PROJECT.md](PROJECT.md)。最初の触れる版に入れるのは上から 6 つで、残りはその後に足す。

- [ ] 毛の描画の試作: 1 部屋に毛を置き、本数ごとの描画の可否と描画時間を CI で測る (`make hairbench`)。レンダラを決め直して ADR に書く
- [ ] 屋敷と一人称の土台: 屋敷の 1 階 (数部屋)、一人称の移動と視点、床・家具・布の表面、表面ごとの毛の本数を 1 か所で持つ状態、残り本数の表示、セーブと読み込み
- [ ] 手で抜く: 毛をつまんで引くと伸びてから抜ける、効果音とカウント、珍しい毛と図鑑、手の強化
- [ ] お金と道具: 買取業者に毛を売る、住人の機嫌と掃除代、道具の購入とレベル (取りこぼしが減る)、取りこぼしの表示、表面ごとの得意・不得意、消耗品 (粘着ローラーの紙)。最初の版の道具は 手・ガムテープ・粘着ローラー・掃除機・毛を光らせるライト
- [ ] 猫と自動化の入口: 猫の通り道と昼寝の場所・また落とす毛、掃除ロボットの配置と巡回の順、何もしなくても数字が増える状態
- [ ] 自動テストプレイ: bot が手で取る段階から自動化まで headless で進めて所要時間を集計する `make simulate` と、描画付きの録画 `make playtest`
- [ ] BGM と効果音 (CC0 の既製の素材。設定画面でオン・オフ)
- [ ] 見た目の方向の反映 (モックで決めた後)
- [ ] 探し物と依頼: 住人の依頼、探し物を傷めない道具の持ち替え、服の毛を取り切る依頼、逃げた猫を連れ戻す
- [ ] 残りの道具と加工: ピンセット・ゴム手袋とスポンジ・業務用の吸引車・粘着シート・ブラシ・毛の加工機と色の仕分け・ダンプカー・アンドロイド
- [ ] 次の建物へ進む: 住人全員がご機嫌で進める、成績、手の強化の持ち越し
- [ ] 建物 2〜4 (ホテル・猫島・街全体) と専用の道具、エンディングの 1 枚絵
- [ ] Steam の公開の経路: Steamworks 連携 (別 ADR)、ストアページ、題名の決定と同名・商標の確認 (bannzai が公開に進むと指示した後)
- [ ] 協力プレイ (1 人プレイの後。中身は未決)

## agent に任せること

bannzai が判断しなかった事項。ここに無い問いも任せる側に落ち、agent は可逆な方を選んで「決めたこと」に記録する。

- 屋敷の毛の総本数、道具ごとの取れる本数の伸び方、各道具の値段、掃除代の額、住人がご機嫌になる線 (自動テストプレイの結果で決める)
- 屋敷の間取り、住人と猫の数・名前・見た目、買取業者の見た目
- 操作の割り当て (キー・マウス)、画面の並び
- レンダラ (毛の描画の試作の結果で決め、ADR に書く)

## 用語

| 用語 | 定義 | 使わない言い換え |
| --- | --- | --- |
| 毛 | 猫が落とした抜け毛 1 本。表面に付いていて、取ると数が減り、売れる | ヘア・ファー |
| 珍しい毛 | ふつうの毛に混じってまれに見つかる毛 (ヒゲ・金色の毛等)。高く売れ、図鑑に載る | レア・レアアイテム |
| 表面 | 毛が付く場所の種類 (床・カーペット・ニット・スーツ・ソファ等)。道具ごとに取りやすさが変わる | 素材・マテリアル |
| 取りこぼし | 道具を 1 回かけた範囲に残った毛。道具のレベルを上げると減る | 残り・ミス |
| 道具 | 毛を取る・見つける・運ぶ・加工するために買う物。手も道具に数える | ツール・アイテム・装備 |
| 粘着ローラー | 粘着する紙を転がして毛を取る道具。紙は消耗品 | 他社の登録商標とされる呼び名 |
| 消耗品 | 使うと減り、お金で買い足す物 (粘着ローラーの紙等) | 弾・リソース |
| 手の強化 | 手で取る力の強化。次の建物へ持ち越せる唯一の物 | スキル・パーク・プレステージ |
| 住人 | 建物に住み、部屋のきれいさに応じて掃除代を払う人 | 依頼主・客・NPC |
| 機嫌 | 住人ごとの状態。部屋に毛が溜まると下がり、掃除代が減る。全員がご機嫌になると次の建物へ進める | 満足度・好感度 |
| 掃除代 | 住人が部屋のきれいさに応じて払うお金。毛の売却と別の収入 | 報酬・給料 |
| 探し物 | 毛の山から出てくる、住人が失くした物。合う道具で丁寧に取ると、お礼が掃除代に上乗せされる | 掘り出し物・落とし物・ドロップ |
| 買取業者 | 建物の裏口に来て毛を買い取る 1 人の人物 | 商人・ショップ |
| 建物 | 1 つの舞台 (屋敷・ホテル・猫島・街全体)。お金と道具は建物ごとに持つ | ステージ・レベル・ワールド |
